# STS2 规则查询与实现基线

查询日期：2026-09-16。采用单机、无进阶难度、非教学局的普通地图规则。来源是作者直接从游戏反编译整理的实现与分析，非 Mega Crit 官方源码发布；因此本项目复现规则，不承诺与任意更新版本的 STS2 同 seed 地图逐点一致。

## 地图

一手移植参考：[StandardActMap 可视化源文件](https://github.com/lfyxhappy/sts2-map-generator-visualizer/blob/master/index.html)。交叉核对：[地图实现](https://github.com/zhiyue/sts2-rl-agent/blob/main/sts2_env/map/generator.py)。两份资料的第二幕问号计数存在差异，本次以可视化作者的分幕模型为准，所有参数集中配置。

- 7 列，生成 7 条向上路径；第二条起点与第一条不同。每步向左上、正上或右上，禁止交叉。
- 先生成连接，再分配房间类型。固定首排普通战斗、倒数第七排宝箱、Boss 前一排休息；其余按数量池分配，放不下的类型轮转，剩余位置补普通战斗。
- 普通单机三幕分别 15、14、13 排可选房间，外加各自 Boss。原作另有 Ancient 起点；本原型以入职标题代替，不实现 Ancient 事件。
- 随机数量：精英5、商店3；问号第一幕截断正态分布均值12、标准差1、范围10–14，第二/三幕减1。随机休息第一幕截断正态均值7、范围6–7；第二幕均值6、范围6–7；第三幕均匀5–6。
- 随机休息/精英不得放在原作坐标 row<6（包含 Ancient 起点，本项目对应零基行号<5）；随机休息不得放在顶端三排。精英、休息、宝箱、商店不与相邻连接同类；分叉子节点优先不同类型。固定排及填充普通战斗不受这条唯一性限制。
- 剪除同起终点、同房间序列的重复分支，尝试补回特殊房间数量；再居中、拉开同排节点、拉直折返。放置限制可能使最终数量低于目标，并非每条路线保证同样房间数。

## 问号房间

依据作者反编译记录的 [UnknownMapPointOdds 与 RunManager](https://github.com/zhiyue/sts2-rl-agent/blob/main/docs/GAME_SYSTEMS_REFERENCE.md#7-unknown-room-odds)：

| 结果 | 初始概率 | 未出现后的增量 |
| --- | --- | --- |
| 普通战斗 | 10% | +10个百分点 |
| 宝箱 | 2% | +2个百分点 |
| 商店 | 3% | +3个百分点 |
| 事件 | 剩余概率，初始85% | 随其他项变化 |

命中的非事件类型重置为初始值，其余允许的类型增加各自基础值；换幕全部重置。上一实际房间是商店，或所有后继节点都是商店时，将商店加入本次黑名单，未占用概率留给事件。普通问号不出精英/休息。房间进入时才确定结果；地图上的问号仍保留，不更改路线或其他节点。确定为事件后才从当前幕未出现过的事件池抽取。

## 卡牌奖励

依据作者反编译记录的 [CardFactory 与 CardRarityOdds](https://github.com/zhiyue/sts2-rl-agent/blob/main/docs/GAME_SYSTEMS_REFERENCE.md#3-card-rewards)：

| 来源 | 白 | 蓝 | 金 |
| --- | --- | --- | --- |
| 普通战斗基础 | 60% | 37% | 3% |
| 精英基础 | 50% | 40% | 10% |
| Boss | 0% | 0% | 100% |
| 商店 | 54% | 37% | 9% |

战斗每张牌独立滚动概率。金卡修正初始−5个百分点；生成非金卡后+1个百分点，最多+40；生成金卡后重置−5。判断先金再蓝：随机数小于「金卡基础+修正」为金，否则小于「金卡基础+修正+蓝卡基础」为蓝，否则为白。负的金卡阈值不先截为0，因此新局第一次普通奖励实际为白65%、蓝35%、金0%。Boss忽略修正强制金卡，同时重置修正。商店使用基础值且不读写修正。事件限定蓝卡/职业随机牌等按其指定池均匀抽取，不动战斗修正。同一组奖励去重。

## 本项目范围

原作随机算法与内容池并未引入；用本项目 Run seed 派生地图、问号、事件、奖励、商店等独立随机序列，所有序列状态存档。三幕敌人和后两幕事件暂用明确标记的占位数据。15个第一幕事件按用户列表实现。没有 Documents 系统，也没有事件改地图效果。
