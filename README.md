# 请上楼 · Please Proceed Upstairs

可直接游玩的单机 roguelike deckbuilder vertical slice。中文界面、一个 Act、三位共享卡池的办事员变体、完整路线和 Boss 结算。卡牌及数值均为占位内容。

## 运行

需要 Node.js 20 或更新版本。**无第三方运行依赖，无需 npm install。**

```sh
npm start
```

浏览器打开 **http://127.0.0.1:4173**。Windows PowerShell 若限制 npm 脚本，可使用 `npm.cmd start`，或直接 `node server.mjs`。可双击项目中的 `启动游戏.cmd`。服务仅监听本机。

```sh
npm test
```

使用 Node 内置测试工具。49 项测试覆盖战斗、地图、存档、Run 流程及三种初始角色的完整合法出牌通关。地图批量验证 1,500 个 seed，并另测配置和确定性。详见 [验收记录](docs/VALIDATION.md)。

## 怎样玩

1. 选择办事员，在「档案编号」输入 seed，点击「开始上楼」。
2. 从地图底部出发，只能沿连接前往下一层。地图上的亮起节点和右侧「下一站」按钮均可点击。
3. 点击手牌，再选择所需敌人或另一张手牌。Esc 取消目标选择。无目标牌会直接使用。
4. 「计入流程」切换归档模式：点击有标记的牌，支付费用、暂不执行，存入流程。再次点击模式按钮退出。
5. 三张牌自动打包。从下个玩家回合起，每个流程依次循环执行 1 → 2 → 3 → 1，免费且不触发普通出牌事件。
6. 「归档」牌可以将任意另一张手牌存入流程，只支付「归档」自己的费用。流程的敌人/卡牌目标自动取首个有效目标。
7. 结束回合时先处理手牌，再进行敌人行动，随后清除玩家格挡、恢复角色规定的能量并抽牌。
8. 打败第 10 层主管、领取奖励，完成本轮。能力、批注、副本、流程只在当前战斗生效；升级、奖励牌、移除牌和遗物在本局永久保留。

点击牌堆查看内容；抽牌堆按名称展示，隐藏真实抽取顺序。卡牌悬停可查看完整文本，「查看详情」列出最终效果、升级、全部批注和副本来源。运行中的流程支持滚动查看，不设数量上限。

### 关键词

- **保留 Retain**：回合结束仍留手中。
- **虚无 Ethereal**：回合结束仍在手中则消耗，优先于保留。
- **消耗 Exhaust**：普通使用后进入消耗堆。
- **能力 Power**：普通使用后进入能力区，监听事件持续生效。
- **副本 Copy**：深复制当前升级、批注、可复制修改，可以复制副本。副本自带虚无，但正常打出后按普通规则进入弃牌堆；本身有消耗或能力属性时仍遵守对应规则。

## 存档

每次操作后自动写入浏览器 `localStorage`。刷新页面后，在标题点击「继续上次办事」。包含当前地图、位置、全部战斗牌堆、修改后的实例、能力/状态、流程、独立游标、随机数状态、奖励领取状态和事件日志。

只有一个本地存档槽；开始新局会替换该槽。换浏览器/端口会使用不同存档空间。开发面板可导出/导入 JSON 存档。导出的格式带版本号；后续不兼容修改需添加迁移逻辑。

## 开发工具

右上角「开发模式」可随时开关：

- 指定 seed 开局；任意卡牌、遗物；加金币、回血、加能量。
- 进入任意占位遭遇、跳转地图节点。
- 升级选中的具体牌、添加复合批注、制造副本、强制计入流程。
- 补齐当前流程的空位为测试防御牌并立即打包。
- 直接判定当前战斗胜利、检查事件日志、导出/导入存档。

战斗内添加卡牌会同时添加至永久牌组和手牌；战斗内升级只修改当前战斗实例。所有开发操作会标记本局。事件日志开关只控制记录，不影响事件监听及机制；保留最近 1,000 条。

## 内容与配置

| 修改内容 | 文件 |
| --- | --- |
| 卡牌定义、数值、升级、组合效果 | `src/data/cards.js` |
| 大角色类、小角色、起始牌组/遗物 | `src/data/characters.js` |
| 敌人、Intent 循环、遭遇组合 | `src/data/enemies.js` |
| 遗物与监听效果 | `src/data/relics.js` |
| 状态和能力 | `src/data/statuses.js` |
| 事件及选项 | `src/data/events.js` |
| Act、节点显示、地图参数 | `src/data/map-config.js` |

共 20 张占位卡、6 件遗物、3 种普通敌人、1 个精英、1 个 Boss、3 个事件。三个办事员槽位共享一个卡池，可直接修改数据。地图支持层数、每层节点范围、类型权重、精英/商店/休息密度系数、额外分叉概率、Boss 前节点规则。早期分叉与终点汇合为结构约束，不受可选分叉概率影响。

## 架构

详细扩展方法与结算时序见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

- `src/core/game.js`：Game / Run、节点转移、消费、永久牌组、Act 进度。
- `src/core/combat.js`：通用战斗循环；不包含任何办事员机制判断。
- `src/core/card.js`：Card Instance、Definition 解析、升级、深复制。
- `src/core/effects.js`：可扩展效果注册表与组合执行。
- `src/core/deck.js`：抽牌、弃牌、消耗、洗牌、移动。
- `src/core/target.js`：根据当前有效效果确定/验证目标。
- `src/core/event-bus.js`：统一事件总线和稳定的监听优先级。
- `src/core/status.js`、`relic.js`、`enemy.js`、`event.js`、`reward.js`：各领域系统。
- `src/core/map.js`、`random.js`、`save.js`：地图、可存储随机状态、存档。
- `src/characters/clerk.js`：办事员专属状态、效果、流程和行动。
- `src/characters/registry.js`：角色机制插件注册。
- `src/ui/`：界面、专属角色面板、文案、SVG 办公插图。

## 原型边界

当前为一个 Act。Run 使用 Act 配置数组决定下一层区域，添加 Act 不必改写战斗核心。正式美术、正式卡表、音效、精细平衡、局外成长和其他大角色尚未制作。窗口适配窄屏，复杂战斗操作优先桌面浏览器。所有资源均在项目内，不需要账号或互联网。
